# 学习资产库复习桥（可选集成）

本目录是给另一个「学习资产库」项目使用的适配材料，不是独立应用，也不会随工作台启动自动安装。普通看课与笔记不依赖此扩展。

- `src/bridge-review.js`：到期卡片、记忆评分与成卡的 HTTP 处理逻辑，复用资产库现有的间隔复习算法。
- `main.js.diff`：资产库 `main.js` 的接入参考补丁，增加 `/review/due`、`/review/grade` 与带来源信息的 `/card`。
- `scripts/bridge-review-check.js`：放到资产库项目后运行的纯函数自检，依赖该项目已有的 `src/srs.js`；不能在本目录直接运行。

接入前需按资产库当前版本核对补丁上下文，将模块与自检脚本放入对应目录。补丁中的历史绝对路径仅说明来源，不是本机必须采用的安装位置；不要直接覆盖资产库现有文件。

工作台默认连接 `127.0.0.1:8791`，可用 `STUDYDESK_VAULT_PORT` 修改。若资产库尚无复习 HTTP 接口，可通过 `STUDYDESK_SRS=/实际路径/学习资产库/src/srs.js` 指定复习规则，让工作台使用自己的本地队列。它仍复用资产库的算法，并不是自带另一套调度器。

适用范围：工作台 v3.6.4 所用桥接协议，整理于 2026-09-30。不同资产库版本应先在副本中验证，再接入真实资料。
