豆包语音转写配置指南

网课学习工作台 · 语音转文字功能 · 全程约 10 分钟
这个功能做什么？

在应用内一键把声音变成带标点、带时间戳的文字，支持三种来源：麦克风（自己说话 / 收外放）、系统声音（网课、直播、会议播放的声音）、本地文件（已录好的音视频）。转写结果自动存入台账，可搜索、编辑、导出 TXT / MD / DOCX。

第一步：开通豆包语音转写（一次性）

1
注册 / 登录火山引擎

打开 console.volcengine.com，用手机号注册并完成实名认证。

2
开通「豆包流式语音识别模型」

控制台搜索「豆包语音」（或访问 语音服务页）→ 找到「豆包流式语音识别模型 2.0」→ 点「开通」。新用户通常有免费额度；计费按小时版时长或并发版选择其一。

选「小时版」资源（默认推荐）则保持本应用默认资源 ID 不动；若你开通的是「并发版」，在应用设置的「模型版本」里切换即可。
3
创建 API Key

控制台 →「API Key 管理」→ 新建 API Key → 复制保存（形如一串密钥，只显示一次）。

4
填入本应用

打开工作台 → 顶栏「直播课堂」→ 找到「豆包语音转写」区 → 点「设置」→ 粘贴 API Key → 保存。徽标变绿「已配置」即可开始转写。

第二步：三种转写来源怎么选

来源适用场景前置条件
麦克风对着麦克风说话；或让麦克风收电脑外放的声音（简洁但受环境音影响）无需额外安装，首次使用允许本地应用使用麦克风
系统声音看网课 / 直播 / 会议时，直接转写「电脑里播放出的声音」，最清晰准确安装 BlackHole 虚拟声卡（见下方）
本地文件已录好的 mp3 / m4a / wav / mp4 等音视频整段转写本机已装 ffmpeg（brew install ffmpeg），你的电脑已具备

收系统声音：安装 BlackHole（一次性，约 3 分钟）

想转写「网课/直播里播出来的声音」而不是麦克风收外放，需要把系统声音接入转写通道：

  1. 终端执行：brew install blackhole-2ch（装完需重启一次电脑）
  2. 系统设置 → 声音 → 输出设备：正常听课时保持你的扬声器/耳机
  3. 在工作台「直播课堂」面板的设备下拉里，转写时选 BlackHole 2ch 作为输入
想「边听边转」两不误？打开「音频 MIDI 设置」（Spotlight 搜索）→ 点左下 + → 创建「多输出设备」→ 勾选你的扬声器 + BlackHole 2ch → 系统输出切到这个多输出设备。这样声音同时从扬声器播出、并被转写通道捕获。

怎么用：一条流程学完不跳出去

1
进课程

顶栏「平台」/「小窗」在内嵌窗口打开小鹅通、腾讯会议、B 站等页面并登录；或直接播放本地视频。

2
开始转写

打开「直播课堂」面板 → 选来源 → 填课程名 → 点「开始转写」。实时字幕逐句出现（带时间戳）。

3
结束保存

点「■ 结束」。结果自动存入「转写台账」，断电重启也不丢。

4
回看利用

台账里点任意记录：可编辑修正、存入笔记、导出 TXT / MD / DOCX。

常见问题

提示「鉴权未通过 / Invalid X-Api-Key」

Key 粘错了或已删除：重新复制粘贴；注意不要带空格。若刚开通服务，等 1–2 分钟再试。

提示「403 被拒绝」

该 Key 未开通「豆包流式语音识别模型」，回控制台开通；或资源 ID 版本与开通的不一致（小时版 ↔ 并发版在设置里切换）。

提示「429 / 限流 / 额度」

免费额度用尽或并发超限：控制台确认余额或购买资源包。转写中断时录音已本地缓存，恢复后可重新转写。

转写没有任何字出来

① 麦克风来源：检查系统设置→声音→输入，对着说话时电平有反应；② 系统声音来源：确认已按上文把声音路由到 BlackHole；③ 音量表（直播面板）有跳动说明采集正常，若不跳动则是来源选错。

长直播会不会丢内容？

已转写的文字每句实时落盘，进程异常退出也不丢已出字的句子；音频同时在本地持续缓存（应用异常恢复后可对缓存音频补转写）。建议 60 分钟以上的课中途手动点一次「结束」再「开始」，分段更稳。
